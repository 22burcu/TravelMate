# 03: Trip-Suche ohne Login zugänglich

## Meta
Status
: **Decided**
Updated
: 07-06-2026

## Problem Statement
Sollen Nutzer Trips durchsuchen können ohne ein Konto zu haben?
Oder soll die gesamte Plattform erst nach der Registrierung 
zugänglich sein?
Laut Happy Path wäre die Registrierung der erste Schritt — 
das kann jedoch neue Nutzer abschrecken bevor sie den 
Mehrwert der Plattform kennenlernen.

## Decision
Die Trip-Suche (`/trips`) ist öffentlich zugänglich ohne Login.
Das Bewerben auf einen Trip erfordert jedoch ein Konto.
So wird die Einstiegshürde gesenkt: Nutzer können die Plattform 
erst kennenlernen bevor sie sich registrieren müssen.

*Decision was taken by:* github.com/Oliwia-Nogacz

## Regarded Options

| Criterion | Alles hinter Login | Suche öffentlich ✅ |
| --- | --- | --- |
| **Einstiegshürde** | ❌ Hoch | ✅ Niedrig |
| **Nutzer gewinnen** | ❌ Abschreckend | ✅ Plattform zuerst kennenlernen |
| **Datenschutz** | ✅ Alle Daten geschützt | ⚠️ Trips öffentlich sichtbar |
| **Happy Path** | ✅ Wie geplant | ⚠️ Bewusste Abweichung |
