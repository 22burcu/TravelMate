# 02: Suchleiste auf der Landing Page statt in der Navbar

## Meta
Status
: **Decided**
Updated
: 05-06-2026

## Problem Statement
Die Trip-Suche muss für Nutzer leicht auffindbar sein. 
Die Frage war: Soll die Suchleiste in der Navbar platziert werden 
(überall sichtbar) oder als zentrales Element auf der Landing Page?

## Decision
Die Suchleiste wurde aus der Navbar entfernt und als großes 
Hero-Element auf der Landing Page platziert.
Ein zentrales Suchelement kommuniziert sofort den Hauptzweck 
der App. Bekannte Plattformen wie Airbnb oder Booking.com 
nutzen dasselbe Muster.

*Decision was taken by:* github.com/Oliwia-Nogacz

## Regarded Options

| Criterion | Navbar | Landing Page Hero |
| --- | --- | --- |
| **Sichtbarkeit** | ✅ Immer sichtbar | ✅ Sofort sichtbar beim Öffnen |
| **Zweck der App** | ⚠️ Geht unter | ✅ Kommuniziert Kernfunktion sofort |
| **Navbar Übersicht** | ❌ Wird überladen | ✅ Navbar bleibt übersichtlich |
| **Bekannte Muster** | ❌ Unüblich | ✅ Airbnb, Booking.com machen es so |
